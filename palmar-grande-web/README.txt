# Palmar Grande — sitio web

## Archivos
- index.html: estructura y contenido.
- styles.css: diseño responsive.
- script.js: menú móvil, navegación y formularios demo.
- assets/palmar-grande-mockup.png: referencia visual generada.

## Cómo verlo
Abrí `index.html` con Chrome, Edge o Firefox.
